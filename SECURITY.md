# Security Policy

Token Yield is a static analytical dashboard and verification suite. It should not require embedded credentials to operate.

## Reporting

Do not publish credentials, private URLs, private datasets, or exploit details in a public issue. Use GitHub private vulnerability reporting when available. If private reporting is unavailable, open a minimal issue without sensitive details and request a private channel.

## Public-repo hygiene

Do not commit API keys, `.env` files, private keys, session URLs, private drafting artifacts, or proprietary customer data. Treat any externally shared calibration data as publishable source material and record its provenance in `docs/calibration-data.md`.
